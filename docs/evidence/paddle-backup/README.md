# PaddleOCR retirado: evidencia de terceros conservada

La integración experimental PaddleOCR fue retirada antes de esta preparación.
No forma parte del runtime ni de los instaladores activos. No se distribuyen
sus paquetes, modelos, capturas, muestras del usuario ni resultados OCR privados.
El informe local original permanece intacto fuera de esta copia publicable.

Se conservan versión/origen, declaraciones de licencia, hashes y avisos registrados
en [installed-artifacts.json](installed-artifacts.json), el
[lock retirado](retired-requirements-paddle-cpu.lock) y el
[catálogo retirado](retired-model-catalog.json). Son evidencia histórica; no deben
instalarse como requisito de Next. Véase el
[inventario](../../THIRD_PARTY_DEPENDENCIES.md) para límites y fuentes de licencias.

This retired experiment is not a runtime requirement. Package/model provenance,
recorded license notices and hashes are retained above. User samples, screenshots
and private OCR outputs are excluded. The original local diagnostics are unchanged.
