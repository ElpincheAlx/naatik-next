ENTREGA
Paquete fuente Fedora x86_64 / CPython 3.14 estándar / CPU. No es RPM.
Incluye instrucciones INSTALACION.md, código, catálogos, pruebas y evidencia.
No incluye Python, venv, ruedas, modelos, diccionarios ni scripts personales.
Verifica SHA256.txt antes de extraer/instalar. Dentro del paquete hay además
un SHA256.txt para comprobar todos los archivos individuales.

Elección cancelable Español/English antes de preparar entorno o descargar,

por perfil. Idioma OCR y ruta/idiomas de traducción permanecen independientes.

Correcciones finales: cancelación obtiene el idioma actual; Escape en captura

idioma español en las aserciones modificadas. Enlaces de evidencia corregidos
en el documento raíz del paquete.

INSTALL / UPDATE
See INSTALACION.md. Extract into a new folder; run bash tools/install.sh.
Choose Español/English before installation; c cancels without creating a venv.
For a fresh noninteractive profile: bash tools/install.sh --language en (or es).
Then ./launch. Help resumes the tutorial; Settings→Language changes UI language.
For repair/update, preserve XDG data and explicit resource paths; rerun the
installer and keep the existing language. Do not uninstall to update.
This source package needs network for a normal install; a verified wheelhouse
allows offline base installation. Optional downloads always need confirmation.
